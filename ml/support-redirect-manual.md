ОПИСАНИЕ ЛИНИЙ ПОДДЕРЖКИ

ЛИНИЯ ПОДДЕРЖКИ L1 — ИНФОРМАЦИОННО-КОНСУЛЬТАЦИОННАЯ

Примеры обращений:
— «Что такое Портал поставщиков и для чего он нужен?»
— «Кто может зарегистрироваться на Портале?»
— «Как зарегистрировать организацию?»
— «Как войти в личный кабинет?»
— «Как восстановить пароль?»
— «Где находятся мои закупки?»
— «Где посмотреть заключённые контракты?»
— «Что такое оферта?»
— «Что такое котировочная сессия?»
— «Как найти закупку?»
— «Где посмотреть инструкцию по работе с контрактами?»
— «Как изменить номер телефона или адрес электронной почты?»
— «Какая электронная подпись нужна для работы на Портале?»
— «Как связаться со службой поддержки?»
— «Как посмотреть статус моего обращения?»

Обращение относится к L1, если на него можно ответить с помощью общей информации, FAQ или одной стандартной инструкции, не анализируя конкретный контракт, закупку, документы, права пользователя или нестандартную ситуацию.

ЛИНИЯ ПОДДЕРЖКИ L2 — ЭКСПЕРТНО-МЕТОДОЛОГИЧЕСКАЯ

Примеры обращений:
— «Как заполнить поле “Обеспечение исполнения контракта”?»
— «Как правильно указать НДС в контракте?»
— «Как оформить изменение условий контракта?»
— «Какие документы необходимо приложить на этом этапе?»
— «Как работать с контрактом в рамках 44-ФЗ?»
— «Какой порядок действий применяется по 223-ФЗ?»
— «Что делать после победы в котировочной сессии?»
— «Почему сотрудник нашей организации не видит контракт?»
— «Какие права нужно назначить сотруднику для подписания документа?»
— «Почему мне недоступна кнопка подписания контракта?»
— «Почему система не принимает введённое значение?»
— «Какую электронную подпись должен использовать сотрудник организации?»
— «Как исправить неправильно заполненную оферту?»
— «Можно ли изменить сведения после публикации оферты?»
— «Почему контракт находится в этом статусе?»
— «Какой тип документа необходимо выбрать?»
— «Почему я не могу выполнить действие на текущем этапе закупки?»
— «Я не могу подписать контракт. Что нужно проверить?»
— «Файл не загружается. Какие требования предъявляются к формату и размеру?»
— «Я правильно заполнил контракт или допустил ошибку?»

Обращение относится к L2, если для ответа необходимо изучить контекст пользователя: его роль, полномочия, конкретный объект, этап закупочного процесса, заполненные поля, документы или применимый нормативный сценарий.

Сообщение пользователя об «ошибке» само по себе не означает, что вопрос не по адресу L2: если сначала необходимо проверить корректность действий, документов, прав, электронной подписи, статуса объекта или заполнения полей, обращение относится к L2.
